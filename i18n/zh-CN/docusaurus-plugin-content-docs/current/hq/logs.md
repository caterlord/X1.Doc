## 开始前

- 确认您已登录正确的 HQ 工作区。
- 确认已选择正确品牌。
- 确认需要调查的是哪间门店或哪台终端。
- 此页用于运营排查。除非内部流程允许，否则不要下载或分享日志。

## 打开此页面

1. 在 Analytics 区域打开 `日志`。
2. 选择 `API 日志` 查看第三方通信，或 `POS 日志` 查看终端文件。

![日志概览](/img/hq/logs/logs_overview_page.jpg)

## 此页用途

`日志` 是 HQ 中日志相关工具的总览页。

- `HQ 稽核轨迹`：即将推出。日后用于查看管理设置和用户操作历史。
- `API 日志`：按品牌或门店查看现有的第三方请求、响应和错误。
- `POS 日志`：现已可用。用于查看 POS 终端上传的日志文件。

`POS 日志` 不会更改 POS 行为。它只协助您查看已由 POS 上传的文件。

## 查看第三方 API 日志

1. 打开 `日志` → `API 日志`。
2. 在 `品牌／门店` 选择所需范围。
3. 选择 `日志类型`。查看 Keeta 菜单同步时，选择 `Keeta / MeiTuan`。
4. 输入 `开始日期 (UTC)` 和 `结束日期 (UTC)`。
5. 点击 `应用`。
6. 点击请求旁的 `查看`，打开 `日志详情`。
7. 展开 `响应内容` 和请求区段，检查结果。

日期包括开始及结束日，最多可选 7 天。请先将问题发生时间转换为 UTC。最新请求显示在最前；使用页面控件查看更多结果。点击 `刷新` 会重新加载已应用的筛选范围。

`仅品牌日志` 不包括门店日志。请选择指定门店以查看其通信记录。只有门店权限的用户只能查看已分配的门店，不能查看品牌日志。

`日志详情` 包括 HTTP 状态、时间、方法、域名、来源、请求查询参数、请求头、响应头和内容。凭证已隐藏，但日志可能仍含其他个人或业务数据，分享前请仔细检查。每个字段最多预览 32,768 个字符，超出时会显示提示。

HTTP 成功不代表第三方已完成操作。请阅读响应，并在第三方系统核实结果。没有日志时，请确认门店、类型和 UTC 日期。数据过多或服务超时时，请缩短日期范围。来源无法使用时，请联系管理员；错误不代表没有记录。

若 `同步菜单` 提示 Keeta 设置未启用，请与管理员检查 MeiTuan 设置中的 `启用 Webhook` 和 `启用菜单同步`。保存所需设置后再重试。查看 API 日志不会启用集成或重试操作。

## 主要区段

![POS 日志页面](/img/hq/logs/pos_logs_page.png)

### 崩溃报告

`崩溃报告` 用于查看 POS 自动上传的崩溃文件。这些文件通常帮助支持人员了解 App 为什么异常停止。

### 应用程序日志

`应用程序日志` 用于查看用户从 POS 手动上传的运行记录。

### Octopus 日志

排查 POS Octopus 付款活动时，使用 `Octopus 日志`。

### 其他上传日志

`其他上传日志` 用于查看不属于其他区段的手动上传诊断文件。

## 主要操作

### 按门店筛选

1. 打开 `POS 日志`。
2. 使用右上方的门店筛选器。
3. 选择 `所有门店` 查看所有已对应门店，或选择单一门店缩小范围。

每个表格每页最多显示 500 行。如有更多文件，使用表格底部的页面控制。

### 在日志区段内搜索

1. 找到需要的区段，例如 `崩溃报告` 或 `应用程序日志`。
2. 使用该区段的搜索栏。
3. 可用文件名称、门店、平台、App 版本或日期文字搜索。

### 快速查看日志

1. 找到日志文件。
2. 选择 `快速查看`。
3. 查看预览内容。
4. 如需完整内容，请下载文件。

大型文件的预览可能只显示文件开头内容。

### 下载日志

1. 找到日志文件。
2. 选择 `下载`。
3. 按内部支持流程保存或分享文件。

## 保存后的影响

此页没有保存操作。查看、筛选、预览和下载日志都不会更改 POS 设置或门店资料。

## 如何检查结果

- 确认所选品牌和门店筛选器正确。
- 确认文件名称、`门店`、`发生时间` 和 `上传时间` 与调查事项相符。
- 对于崩溃报告，升级处理前先检查 `平台` 和 `App 版本`。

## 如果出现问题

- 如页面显示 `找不到日志`，确认已选择正确品牌和门店。
- 如找不到门店，确认该门店已有 POS 门店对应。
- 如找不到文件，请 POS 用户再次从 POS 终端上传日志。
- 如 `快速查看` 显示内容不足，使用 `下载`。

## 何时需要找老板／管理员

- 您没有需要品牌或门店的访问权限。
- 日志可能包含顾客或员工敏感资料。
- 您需要将文件发送到组织外部。
- 您正在调查重复崩溃、付款失败或安全相关活动。
