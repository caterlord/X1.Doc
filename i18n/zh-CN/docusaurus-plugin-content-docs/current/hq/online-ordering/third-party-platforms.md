## 开始前

- 确认已选择正确的品牌与目标门店。
- 事先准备好平台提供的门店代码、API key、Webhook 信息或支付方式 ID。
- 确认该平台是外送平台、纯集成平台，还是主要由合作伙伴代管。

## 打开此页面

打开 `网上点餐` -> `一般设置`，然后打开目标门店，再选择 `第三方平台`。

## 本页用途

`第三方平台` 用于管理某一家门店的线上点餐平台服务连接。

您可以在这里：

- 通过 `新增平台` 订阅新的外送或集成平台
- 查看哪些已订阅平台可供该门店使用
- 输入或更新门店级平台字段值
- 设置 Foodpanda 的 `连接 Foodpanda`、订单总额及自动更新选项
- 在保存设置后使用 `同步菜单`，将最新菜单发送到 Foodpanda 或 MeiTuan
- 从门店已保存设置中移除某个平台卡片

本页是门店级。订阅本身发生在品牌／公司级，但您在这里输入的字段只会应用到当前打开的门店。

![第三方平台页面](/img/hq/online-ordering/oo_third_party_platforms_page.png)

*`第三方平台` 显示 `新增平台`、平台分组卡片，以及订阅状态标签。*

## 主要区域

### 新增平台

选择 `新增平台`，会打开只显示 `第三方平台` 的市集选择器。

当您选择 `订阅` 后，窗口会关闭，平台也会回到 `第三方平台` 页面中显示。

### 平台分组

HQ 会将平台卡片分组为：

- `外送平台`
- `整合平台`
- `其他`

### 平台卡片

每张平台卡片可能显示以下状态：

- `已订阅`：平台已启用可用
- `未订阅`：平台仍可见，但在重新订阅前不能编辑
- 没有标签且没有字段：该平台当前没有有效门店设置

有些卡片会显示可编辑字段。有些则只会显示 `无需设置 — 此集成由合作伙伴平台管理。`

`MeiTuan` 卡片包含付款、折扣、服务费、Webhook 和菜单同步设置。如果合作伙伴提供 Webhook 存取资料，还要填写 `API URL`、`Shop ID`、`Access Token`、`Refresh Token` 和 `Token 到期日期/时间`。请把两个 Token 字段视为机密凭证。

### 保存操作

卡片上的更改，必须在 `门店设置` 页面级点击 `保存设置` 后才会完整生效。

### Foodpanda

Foodpanda 卡片从 `连接 Foodpanda` 开始。输入合作伙伴提供的 `API URL`、`API 用户名` 和 `API 密码`，然后在 `Foodpanda 门店资料` 填写 `Chain Code`、`Remote ID` 和 `Vendor ID`。

在 `订单总额` 中，使用可搜索的选择器选择 `付款方式` 和可选的 `折扣`。选择器可以清除。如果已保存的 ID 已不可用，HQ 会保留 `无法使用的 ID（{id}）`，方便您识别并替换。

同一区域包含 `将折扣计入订单总额` 和 `将包材费计入订单总额`。开启包材费开关后，请在 `包材费菜品` 中选择一个可售菜品。选择器支持 `搜索项目` 和 `按分类浏览`；可按菜品代号、名称或备用名称搜索，然后选择 `选择项目`。

只有在合作伙伴要求时，才展开 `更多订单选项`。可用控件包括 `折扣金额不四舍五入`、`仅将指定折扣计入总金额` 和 `要包含的折扣`。请输入 X1 中显示的折扣名称，并以逗号分隔。

在 `自动更新` 下，使用 `接收订单更新` 和 `自动同步菜单` 选择 Foodpanda 与 X1 交换的更新。

### 手动菜单同步

Foodpanda 和 MeiTuan 会显示 `菜单同步` 区域及 `同步菜单`。请先保存页面；有未保存变更时，按钮会停用，页面显示 `请先保存设置，再同步菜单`。保存后选择 `同步菜单`，将最新已保存的菜单发送出去。成功后会显示 `菜单同步请求已发送。`

## 步骤

1. 打开 `网上点餐` -> `一般设置`。
2. 找到正确的 `门店名称`。
3. 选择该门店的编辑操作，打开 `门店设置`。
4. 选择 `第三方平台`。
5. 如果平台尚未列出，选择 `新增平台`。
6. 对需要的平台选择 `订阅`。
7. 如果有字段可填，展开平台卡片。
8. 输入所需的门店级信息。
9. 对于 `Foodpanda`，完成 `连接 Foodpanda`、`Foodpanda 门店资料` 及所需的 `订单总额` 对应。
10. 对于 `MeiTuan`，先填写合作伙伴提供的 `API URL`、`Shop ID`、`Access Token`、`Refresh Token` 和 `Token 到期日期/时间`，再开启 `启用 Webhook`。
11. 选择 `保存设置`。
12. 如果平台显示 `菜单同步`，请在设置保存后选择 `同步菜单`。

## 保存后的影响

保存后，所选门店的平台设置会更新。

平台订阅本身也会影响其他 HQ 区域：

- 平台会出现在 `第三方平台`
- 相关渠道可能会出现在 `渠道设置`
- 之后如果取消订阅，可能会移除已保存的门店级平台设置

## 如何检查你的变更

1. 重新打开同一家门店，确认平台卡片仍然存在。
2. 刷新后，确认已保存的值仍保留在卡片上。
3. 如果平台应该解锁某个订单渠道，请再检查 `渠道设置`。
4. 如果有安全的测试路径，请在下游前台或合作伙伴流程中验证。

## 如发生问题

- 确认平台确实已通过 `新增平台` 完成订阅。
- 确认您编辑的是正确门店，而不只是正确品牌。
- 对于 `Foodpanda`，请替换任何 `无法使用的 ID（{id}）`，确认已选择 `包材费菜品`，并在选择 `同步菜单` 前保存设置。
- 如果 `同步菜单` 停用，请先保存页面。不要使用尚未保存的菜单作为同步来源。
- 如果卡片显示 `未订阅`，请先重新订阅再尝试编辑。
- 如果卡片没有字段，不要反复重试；该集成可能由合作伙伴代管。
- 如果平台在取消订阅后消失，请回到 `市集` 或 `新增平台` 重新订阅，再重新输入信息。

## 何时请店主／管理员协助

- 您没有平台账号资料、门店识别码或凭证。
- 平台会影响营业中的顾客订单、外送派送或结算。
- 您打算取消一个可能仍被营业中门店使用的平台。
