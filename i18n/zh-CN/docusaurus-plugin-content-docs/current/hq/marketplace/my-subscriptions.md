title: 我的订阅

:::info[适用对象]
需要检查 X1 POS 设备席位，或管理当前品牌启用中市集订阅的管理员。
:::

## 开始前

- 在左上角选择器确认正确的工作区和品牌。
- 请使用有权管理该品牌的管理员账户配对或释放设备。
- 配对前，将新平板或替换平板连接到互联网，并打开 X1 POS 设置流程。
- 只有在当前平板已损坏、遗失或永久替换时，才释放 POS 设备席位。
- 释放旧设备前，先确认替换平板已准备好注册。
- 先确认移除市集订阅是否会影响营业中的门店或集成。
- 如果已从某台终端删除 POS 门店配置，请在本页确认相关席位已重新变为可用。

## 打开此页面

在侧边栏打开 `市集与帐单` → `我的订阅`。

- 选择 `X1 产品`，查看席位、配对平板或释放设备。
- 选择 `市集`，查看和管理市集产品订阅。

## 本页控制内容

`我的订阅` 控制两类订阅。

### X1 POS 设备席位

使用 `X1 产品` 检查所选品牌的 POS 订阅席位。

`X1 POS 设备席位` 表格会显示：

| 字段 | 说明 |
| --- | --- |
| `门店` | 席位所属门店。 |
| `状态` | `已占用` 表示已有设备使用该席位。`配对中` 表示设置正在进行。`可用` 表示平板可注册到该门店。 |
| `设备` | 可用时显示 POS 设备名称。如果未提供设备名称，HQ 会显示缩短的设备 ID 和 `未提供设备名称`。 |
| `启用时间` | 设备占用席位的时间。 |
| `最后上线` | 该 POS 设备最后一次检查订阅的时间。 |
| `订阅期间` | 如有设置开始或结束日期，会显示席位期间。 |
| `操作` | 在可用席位选择 `配对设备`，在已占用席位选择 `释放设备`。使用 HQ 配对的席位可显示 `重新生成代码` 和 `取消配对` 图标。 |

表格上方摘要会显示 `总席位`、`已使用席位`、`配对中` 和 `可用席位`。

![X1 POS 设备席位统计及已占用、配对中和可用的席位](/img/hq/marketplace/my-subscriptions/zh-CN/seat-overview.png)

*选择操作前，先查看席位统计、门店和状态。本页的画面使用示例数据。*

### 市集订阅

使用 `市集` 检查当前品牌已订阅的市集产品。

根据产品不同，页面可能会提供以下操作：

- `设置`
- `取消订阅`

`设置` 只会出现在有直接配置页面的产品。由市集管理的 `3rd Party Platforms` 通常要改到 [General Settings](../online-ordering/general-settings.md) 和 [3rd Party Platforms](../online-ordering/third-party-platforms.md) 继续处理。

## 步骤

### 配对 POS 平板

1. 在 `我的订阅` 选择 `X1 产品`。
2. 找到正确门店的 `可用` 席位。
3. 在该行选择 `配对设备`。`配对 X1 POS 设备` 窗口会显示代码和过期倒计时。
4. 在平板的 X1 POS 设置流程中，点击 `使用配对码配对`。
5. 在平板的 `配对码` 字段输入 HQ 当前显示的代码。
6. 在平板点击 `配对设备`。
7. 在平板完成设置。HQ 显示 `设备已连接` 后，请保持窗口打开，直到激活完成。

![配对 X1 POS 设备窗口，显示示例代码、过期倒计时和配对操作](/img/hq/marketplace/my-subscriptions/zh-CN/pair-device.png)

*请使用自己 HQ 窗口显示的代码。如果需要在平板连接前更换代码，选择 `重新生成代码`，再在平板输入新代码。*

### 取消配对

1. 在配对窗口选择 `取消配对`。如果窗口已关闭，可以在对应的 `配对中` 席位选择 `取消配对` 图标（如有显示）。选择 `关闭` 会让配对继续进行。
2. 确认显示 `配对已取消。`，并确认席位恢复为 `可用`。

![配对已取消的成功通知](/img/hq/marketplace/my-subscriptions/zh-CN/cancel-pairing-success.png)

*出现此通知后，HQ 已取消配对。*

### 释放已替换的 POS 平板

1. 在 `我的订阅` 选择 `X1 产品`。
2. 找到相关门店的 `已占用` 席位。
3. 查看 `设备`、`启用时间` 和 `最后上线`，确认这是旧平板。
4. 在 `操作` 选择 `释放设备` 图标。
5. 阅读警告，并核对确认窗口中的设备和门店。
6. 选择 `释放设备` 以释放席位，或选择 `取消` 以保留当前设备。
7. 确认显示 `已释放设备订阅。`，并确认席位变为 `可用`。

![释放设备确认窗口，显示旧平板、门店、警告和确认按钮](/img/hq/marketplace/my-subscriptions/zh-CN/release-device.png)

*确认前，请再次核对门店和平板。*

![已释放设备订阅的成功通知](/img/hq/marketplace/my-subscriptions/zh-CN/release-device-success.png)

*出现此通知后，替换平板可以使用已释放的席位。*

### 管理市集订阅

1. 打开 `我的订阅`。
2. 选择 `市集`。
3. 找到要管理的订阅。
4. 如果产品有设置页面，选择 `设置`。
5. 如果产品已不再需要，选择 `取消订阅`。
6. 如系统有提示，请确认取消订阅。

## 保存后的影响

释放 POS 设备席位不会取消订阅。它只会清除旧设备占用，让另一部平板可以注册。旧平板再次上线并检查订阅时，会失去访问权。

POS 终端启用或验证订阅时会记录设备名称。较早已占用的席位，在该平板使用当前 app 回报前，可能会显示缩短设备 ID 和 `未提供设备名称`。

当 POS 终端删除门店配置时，app 会先释放该终端占用的 POS 订阅席位，再删除本机门店配置。如果 POS 显示 `无法停用订阅`，请先让管理员或支持在 HQ 确认席位状态，不要继续删除本机设置。

移除市集订阅后，相关功能或集成可能会立即不可用。

对于由市集管理的线上点餐平台，取消订阅也可能移除相关渠道可用性，并清除门店级已保存的平台设置。请将 `取消订阅` 视为高影响变更。

## 如何检查你的变更

1. 激活后，确认显示 `X1 POS 设备已成功配对。`，并检查正确门店的席位是否变为 `已占用`，以及 `设备` 栏是否显示新平板。
2. 确认平板已完成设置并打开 POS 登录界面。
3. 如果席位列表还未更新，选择 `刷新` 再检查状态。
4. 如保留市集订阅，确认产品仍出现在列表中。
5. 如移除市集订阅，确认它已从启用中订阅列表消失。
6. 如果您移除了平台订阅，营业前请重新检查 [Channel Settings](../online-ordering/channel-mapping.md) 或 [3rd Party Platforms](../online-ordering/third-party-platforms.md)。

## 如发生问题

- 如果显示 `请选择品牌以查看 X1 POS 订阅席位。`，请先选择正确品牌。
- 如果显示 `此品牌找不到 X1 POS 订阅席位。`，请确认该品牌已分配 X1 POS 席位。
- 如果显示 `X1 POS subscription database is unavailable`，请联系支持检查 production 订阅数据库连接。
- 如果无法使用配对，请管理员确认该账户是否已启用设备配对。如有权限，也可以[使用 HQ 登录设置平板](../../getting-started/first-time-initialization.md)。
- 如果代码在平板连接前过期，选择 `重新生成代码`，再输入当前显示的代码。
- 如果释放了错误设备，请重新注册正确平板，或在旧平板被再次使用前联系支持。
- 如果已删除 POS 门店配置，但席位仍显示 `已占用`，请联系支持检查该终端释放席位时是否失败。
- 如果是误取消订阅，请回到 [市集](./catalog.md) 重新订阅（如产品仍可使用）。

## 何时请店主／管理员协助

- 您不确定应释放哪一部平板。
- 该平板可能仍在营业中的门店使用。
- 订阅会影响营业中的支付、点餐或财务流程。
- 您不确定是否仍有其他团队或门店在使用该市集产品。
