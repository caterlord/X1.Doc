title: 我的訂閱

:::info[適用對象]
需要檢查 X1 POS 裝置席位，或管理目前品牌啟用中市集訂閱的管理員。
:::

## 開始前

- 在左上角選擇器確認正確的工作區和品牌。
- 請使用有權管理該品牌的管理員帳戶配對或釋放裝置。
- 配對前，將新平板或替換平板連接至互聯網，並開啟 X1 POS 設定流程。
- 只有在目前平板已損壞、遺失或永久替換時，才釋放 POS 裝置席位。
- 釋放舊裝置前，先確認替換平板已準備好註冊。
- 先確認移除市集訂閱是否會影響營業中的店舖或整合。
- 如果已從某台終端刪除 POS 店舖設定，請在本頁確認相關席位已重新變為可用。

## 開啟此頁面

在側邊欄開啟 `市集及帳單` → `我的訂閱`。

- 選擇 `X1 產品`，查看席位、配對平板或釋放裝置。
- 選擇 `市集`，查看和管理市集產品訂閱。

## 本頁控制內容

`我的訂閱` 控制兩類訂閱。

### X1 POS 裝置席位

使用 `X1 產品` 檢查所選品牌的 POS 訂閱席位。

`X1 POS 裝置席位` 表格會顯示：

| 欄位 | 說明 |
| --- | --- |
| `店舖` | 席位所屬店舖。 |
| `狀態` | `已佔用` 表示已有裝置使用該席位。`配對中` 表示設定正在進行。`可用` 表示平板可註冊至該店舖。 |
| `裝置` | 可用時顯示 POS 裝置名稱。如果未提供裝置名稱，HQ 會顯示縮短的裝置 ID 和 `未提供裝置名稱`。 |
| `啟用時間` | 裝置佔用席位的時間。 |
| `最後上線` | 該 POS 裝置最後一次檢查訂閱的時間。 |
| `訂閱期間` | 如有設定開始或結束日期，會顯示席位期間。 |
| `操作` | 在可用席位選擇 `配對裝置`，在已佔用席位選擇 `釋放裝置`。使用 HQ 配對的席位可顯示 `重新產生代碼` 和 `取消配對` 圖示。 |

表格上方摘要會顯示 `總席位`、`已使用席位`、`配對中` 和 `可用席位`。

![X1 POS 裝置席位統計及已佔用、配對中和可用的席位](/img/hq/marketplace/my-subscriptions/zh-HK/seat-overview.png)

*選擇操作前，先查看席位統計、店舖和狀態。本頁的畫面使用示範資料。*

### 市集訂閱

使用 `市集` 檢查目前品牌已訂閱的市集產品。

依產品不同，頁面可能會提供以下動作：

- `設定`
- `取消訂閱`

`設定` 只會出現在有直接設定頁面的產品。由市集管理的 `3rd Party Platforms` 通常要改到 [General Settings](../online-ordering/general-settings.md) 與 [3rd Party Platforms](../online-ordering/third-party-platforms.md) 繼續處理。

## 步驟

### 配對 POS 平板

1. 在 `我的訂閱` 選擇 `X1 產品`。
2. 找到正確店舖的 `可用` 席位。
3. 在該列選擇 `配對裝置`。`配對 X1 POS 裝置` 視窗會顯示代碼和到期倒數。
4. 在平板的 X1 POS 設定流程中，點選 `使用配對碼配對`。
5. 在平板的 `配對碼` 欄位輸入 HQ 目前顯示的代碼。
6. 在平板點選 `配對裝置`。
7. 在平板完成設定。HQ 顯示 `裝置已連線` 後，請保持視窗開啟，直到啟用完成。

![配對 X1 POS 裝置視窗，顯示示範代碼、到期倒數和配對操作](/img/hq/marketplace/my-subscriptions/zh-HK/pair-device.png)

*請使用自己 HQ 視窗顯示的代碼。如需在平板連線前更換代碼，選擇 `重新產生代碼`，再在平板輸入新代碼。*

### 取消配對

1. 在配對視窗選擇 `取消配對`。若視窗已關閉，可在對應的 `配對中` 席位選擇 `取消配對` 圖示（如有顯示）。選擇 `關閉` 會讓配對繼續進行。
2. 確認顯示 `配對已取消。`，並確認席位回到 `可用`。

![配對已取消的成功通知](/img/hq/marketplace/my-subscriptions/zh-HK/cancel-pairing-success.png)

*出現此通知後，HQ 已取消配對。*

### 釋放已替換的 POS 平板

1. 在 `我的訂閱` 選擇 `X1 產品`。
2. 找到相關店舖的 `已佔用` 席位。
3. 查看 `裝置`、`啟用時間` 和 `最後上線`，確認這是舊平板。
4. 在 `操作` 選擇 `釋放裝置` 圖示。
5. 閱讀警告，並核對確認視窗中的裝置和店舖。
6. 選擇 `釋放裝置` 以釋放席位，或選擇 `取消` 以保留目前的裝置。
7. 確認顯示 `已釋放裝置訂閱。`，並確認席位變為 `可用`。

![釋放裝置確認視窗，顯示舊平板、店舖、警告和確認按鈕](/img/hq/marketplace/my-subscriptions/zh-HK/release-device.png)

*確認前，請再次核對店舖和平板。*

![已釋放裝置訂閱的成功通知](/img/hq/marketplace/my-subscriptions/zh-HK/release-device-success.png)

*出現此通知後，替換平板可以使用釋放出的席位。*

### 管理市集訂閱

1. 開啟 `我的訂閱`。
2. 選擇 `市集`。
3. 找到要管理的訂閱。
4. 如果產品有設定頁，選擇 `設定`。
5. 如果產品已不再需要，選擇 `取消訂閱`。
6. 如系統有提示，請確認取消訂閱。

## 儲存後的影響

釋放 POS 裝置席位不會取消訂閱。它只會清除舊裝置佔用，讓另一部平板可以註冊。舊平板再次上線並檢查訂閱時，會失去存取權。

POS 終端啟用或驗證訂閱時會記錄裝置名稱。較早已佔用的席位，在該平板使用目前 app 回報前，可能會顯示縮短裝置 ID 和 `未提供裝置名稱`。

當 POS 終端刪除店舖設定時，app 會先釋放該終端佔用的 POS 訂閱席位，再刪除本機店舖設定。如果 POS 顯示 `無法停用訂閱`，請先讓管理員或支援在 HQ 確認席位狀態，不要繼續刪除本機設定。

移除市集訂閱後，相關功能或整合可能會立即不可用。

對於由市集管理的網上點餐平台，取消訂閱也可能移除相關渠道可用性，並清除店舖層級已儲存的平台設定。請將 `取消訂閱` 視為高影響變更。

## 如何檢查你的變更

1. 啟用後，確認顯示 `X1 POS 裝置已成功配對。`，並檢查正確店舖的席位是否變為 `已佔用`，以及 `裝置` 欄是否顯示新平板。
2. 確認平板已完成設定並開啟 POS 登入畫面。
3. 如果席位清單尚未更新，選擇 `重新整理` 再檢查狀態。
4. 如保留市集訂閱，確認產品仍出現在清單中。
5. 如移除市集訂閱，確認它已從啟用中訂閱清單消失。
6. 如果您移除了平台訂閱，營業前請重新檢查 [Channel Settings](../online-ordering/channel-mapping.md) 或 [3rd Party Platforms](../online-ordering/third-party-platforms.md)。

## 如發生問題

- 如果顯示 `請選擇品牌以查看 X1 POS 訂閱席位。`，請先選擇正確品牌。
- 如果顯示 `此品牌找不到 X1 POS 訂閱席位。`，請確認該品牌已分配 X1 POS 席位。
- 如果顯示 `X1 POS subscription database is unavailable`，請聯絡支援檢查 production 訂閱資料庫連線。
- 如果無法使用配對，請管理員確認該帳戶是否已啟用裝置配對。如有權限，也可以[使用 HQ 登入設定平板](../../getting-started/first-time-initialization.md)。
- 如果代碼在平板連線前到期，選擇 `重新產生代碼`，再輸入目前顯示的代碼。
- 如果釋放了錯誤裝置，請重新註冊正確平板，或在舊平板被再次使用前聯絡支援。
- 如果已刪除 POS 店舖設定，但席位仍顯示 `已佔用`，請聯絡支援檢查該終端釋放席位時是否失敗。
- 如果是誤取消訂閱，請回到 [市集](./catalog.md) 重新訂閱（如產品仍可使用）。

## 何時要請店主／管理員協助

- 您不確定應釋放哪一部平板。
- 該平板可能仍在營業中的店舖使用。
- 訂閱會影響營業中的付款、點餐或財務流程。
- 您不確定是否仍有其他團隊或店舖在使用該市集產品。
