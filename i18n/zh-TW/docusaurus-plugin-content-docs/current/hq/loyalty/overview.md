:::info[適用對象]
本頁適合準備為品牌啟用原生、電子錢包優先會員獎賞的店主與 HQ 管理員。
:::

## 開始前

- 確認你正在正確的品牌操作。
- 決定哪些店舖可以在 POS 接受會員獎賞卡。
- 準備計劃名稱、公開代碼、貨幣、積分規則與兌換價值。
- 在 POS 結帳流程正式啟用前，先把本頁視為預覽設定。

## 開啟頁面

開啟 `會員獎賞` -> `計劃`。

## 本頁控制什麼

`會員獎賞` 控制所選品牌的 X1 原生會員獎賞計劃。

你可以在這裡：

- 建立或更新計劃
- 啟用或停用計劃
- 設定 `計劃名稱`、`公開代碼`、`貨幣`、`預設級別`、積分比例與兌換價值
- 為指定店舖啟用計劃
- 選擇 `同步 POS 金鑰`，讓 POS 在下次設定同步後可連接 X1 Native Loyalty
- 複製 `登記端點`，用於 QR、電子錢包或推廣活動設定

原生會員獎賞以電子錢包與匿名卡為先。客人不需要提供姓名、電郵或電話也可以取得會員卡。只有在商戶有明確原因及同意時，才應收集聯絡資料。

## 步驟

1. 開啟 `會員獎賞` -> `計劃`。
2. 選擇 `新增計劃`。
3. 輸入 `計劃名稱`。
4. 輸入小寫 `公開代碼`。
5. 設定 `貨幣`。
6. 設定 `每貨幣單位積分`。
7. 設定 `每分兌換價值`。
8. 準備好後，開啟 `已啟用計劃`。
9. 選擇 `儲存`。
10. 在 `分店啟用` 中，開啟可接受此計劃的店舖。
11. 為每間已啟用店舖選擇 `同步 POS 金鑰`。
12. 複製 `登記端點`，供電子錢包卡或推廣 QR 設定使用。

## 儲存後的影響

- 計劃設定會儲存在原生會員獎賞資料庫。
- 分店啟用狀態會控制哪些店舖可以接受已掃描的會員獎賞卡。
- `同步 POS 金鑰` 會寫入會員獎賞開關、API URL 與 POS 金鑰到店舖設定，讓終端機透過現有 POS 設定同步取得。
- 發卡與積分增減事件會寫入流水帳及 outbox，供日後 BI 匯出使用。

## 如何檢查變更

1. 重新開啟 `會員獎賞` -> `計劃`。
2. 確認已儲存計劃出現在列表。
3. 確認 `分店啟用` 中的店舖正確。
4. 測試掃描或結帳前，確認 POS 已完成設定同步。

## 如發生問題

- 如果無法儲存計劃，檢查 `計劃名稱` 和 `公開代碼` 是否已填寫。
- 如果公開代碼被拒絕，改用只含小寫字母、數字及連字號的代碼。
- 如果店舖啟用後仍無法接受會員獎賞，重新選擇 `同步 POS 金鑰`，並等待 POS 完成設定同步。
- 如果電子錢包 pass 不能下載，請 rollout 負責人確認該環境的 Apple Wallet 與 Google Wallet 發卡設定。

## 何時要請店主／管理員協助

- 你不確定哪些店舖應接受此計劃。
- 你正在修改已上線計劃的積分或兌換價值。
- 你需要收集客人聯絡資料。
- 你需要 Apple Wallet pass 簽署、Google Wallet 發卡或 BI 匯出設定。
