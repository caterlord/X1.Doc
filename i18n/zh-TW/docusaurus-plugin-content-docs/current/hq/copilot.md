# HQ Copilot

HQ Copilot 可在 HQ 入口網站協助完成多步驟商戶工作。說明目標、檢查可編輯計畫，再選擇 **開始目標**。Copilot 可跨多輪對話繼續工作，並在需要資料、核准、重新登入或更多點數時暫停。

:::info 預覽功能
HQ Copilot 依工作區控制，預設為停用。工作區擁有人或管理員須在 **市集與帳單 → 帳單 → Copilot 點數與控制** 啟用。
:::

## 開始及引導目標

1. 選擇正確的商戶工作區及品牌。
2. 在頂部列選擇 **開啟 HQ Copilot**。
3. 說明結果；需要時加入日期、店鋪、管道及例外。
4. 選擇 Luna、Terra 或 Sol。只有管理員允許時才會提供 Sol 快速模式。
5. 設定目標點數預算；Copilot 會在超出預算前暫停。
6. 可附加最多五個 CSV、XLS、XLSX、PDF、JPG、PNG 或 WebP 檔案，每個不超過 2 MB。
7. 選擇 **建立計畫**，視需要修改步驟標題，再選擇 **開始目標**。

目標執行期間可透過訊息補充資料或改變方向，也可 **暫停**、**繼續** 或 **取消目標**。工作區政策最高可允許每位使用者同時執行三個目標。

## 檢查及確認操作

Copilot 可讀取 HQ 資料及準備操作預覽，但不會自行變更商戶設定。寫入操作必須在核准卡上確認。高風險操作需要最新登入狀態，並輸入畫面所示確認字句。如其他使用者修改同一資源，預覽可能過期或發生衝突，Copilot 會重新準備。操作完成後，Copilot 會重新讀取資源，才會報告步驟完成。

如工作區、品牌、店鋪、金額、受影響記錄或警告不符合預期，請勿核准。

## 模型、點數及帳單

**Luna** 適合日常查詢及明確變更；**Terra** 適合較廣泛設定及分析；**Sol** 適合複雜、含糊或長時間目標；**Sol 快速模式** 使用優先處理，成本較高並須由管理員啟用。

每個 Clerk 工作區每週獲得 250 個免費點數，先用免費點數，再用已購買點數。費用按有效版本費率卡，以 AI 供應商成本的兩倍計算。擁有人及管理員可查看用量和帳目、透過 Stripe 購買點數、儲存付款卡、設定有每月上限的自動加值，以及控制保留期、模型、同時目標數和每個目標預算。付款爭議會暫停付費用量，未用的每週點數不會累積。

## 從檔案匯入菜單

附加來源菜單，並說明目標品牌或店鋪、貨幣、稅務處理，以及要合併還是取代現有記錄。Copilot 會先找出欄位、重複項目、缺少價格、不明確的加料群組及破壞性取代。確認前請檢查欄位對應和每個預覽。附件內容只視為商戶資料，Copilot 不會執行檔案內的指令。

## 隱私、限制及恢復

管理員可把對話保留期設為 0、7、30 或 90 天。供應商回應會要求不在供應商端儲存；為可靠性、安全、帳單及爭議處理，系統可另行保留檢查點、稽核事件、用量記錄及核准證據。

Copilot 不會管理 Clerk 成員或驗證、內部控制平台、購買付款卡或機密資料。所有操作仍受現有 HQ 權限限制。如工作程序重新啟動，請從 **目標紀錄** 開啟目標，重新登入後選擇 **繼續**；Copilot 會從最後檢查點繼續。
