title: 報表
---

:::info[適用對象]
經理與店主，用來檢視店舖績效與稽核紀錄。
:::

## 開始前

- 您已登入且具備報表存取權限
- 如果需要紙本，印表機已就緒

## 此畫面用途

使用 `Reports` 選擇報表類型、設定日期或條件、查看結果，並在需要時列印。

## 步驟

1. 點選 `Reports`。
2. 從報表清單選擇報表類型。
3. 選擇日期與需要的選項（例如如果有提示就輸入抽屜代碼）。
4. 等待報表載入。
5. 如果需要紙本，點選 `Print`。

## 查看全單取消紀錄

1. 點選 `報表`。
2. 選擇 `14. 全單取消報表`。
3. 選擇所需日期或報表條件。
4. 查看 `取消時間`、`交易`、`餐檯`、`操作人員`、`員工編號`、`取消原因`、`品項明細` 與 `原品項總額`。
5. 如需紙本稽核紀錄，點選 `列印`。

當您需要確認整張訂單由誰取消、取消原因，以及涉及哪些品項和原始金額時，請使用此報表。

## 你應該看到什麼

- 報表選擇器、日期控制項與 `Print` 按鈕
- 報表內容區會依照所選報表更新
- `全單取消報表` 會顯示每張全單取消訂單的操作人員、原因、原品項總額與品項明細

## 如發生問題

:::warning[報表是空白或載入很慢]
先確認日期／範圍，再重試一次。
:::

## 何時要找經理／管理員

- 需要的報表類型缺少
- 列印出的報表與畫面結果不一致

## 部分付款的歸屬時間

付款報表會把每筆已儲存付款歸入實際收款的工作日、時段、收銀員和錢箱。銷售收入與最終交易表頭只在訂單完成時入帳。例如：週三收取的 $80 顯示於週三付款總額；若週四再收 $70 並完成 $150 訂單，週四顯示 $70 付款及 $150 銷售收入。
