# HQ Copilot

HQ Copilot 可在 HQ 门户协助完成多步骤商家工作。说明目标、检查可编辑计划，再选择 **开始目标**。Copilot 可跨多轮对话继续工作，并在需要资料、批准、重新登录或更多点数时暂停。

:::info 预览功能
HQ Copilot 按工作区控制，默认停用。工作区所有者或管理员须在 **市集与账单 → 账单 → Copilot 点数与控制** 启用。
:::

## 开始及引导目标

1. 选择正确的商家工作区及品牌。
2. 在顶部栏选择 **打开 HQ Copilot**。
3. 说明结果；需要时加入日期、门店、渠道及例外。
4. 选择 Luna、Terra 或 Sol。只有管理员允许时才会提供 Sol 快速模式。
5. 设置目标点数预算；Copilot 会在超出预算前暂停。
6. 可附加最多五个 CSV、XLS、XLSX、PDF、JPG、PNG 或 WebP 文件，每个不超过 2 MB。
7. 选择 **创建计划**，按需修改步骤标题，再选择 **开始目标**。

目标执行期间可通过消息补充资料或改变方向，也可 **暂停**、**继续** 或 **取消目标**。工作区政策最高可允许每位用户同时执行三个目标。

## 检查及确认操作

Copilot 可读取 HQ 数据及准备操作预览，但不会自行更改商家设置。写入操作必须在批准卡上确认。高风险操作需要最新登录状态，并输入画面所示确认短语。如其他用户修改同一资源，预览可能过期或发生冲突，Copilot 会重新准备。操作完成后，Copilot 会重新读取资源，才会报告步骤完成。

如工作区、品牌、门店、金额、受影响记录或警告不符合预期，请勿批准。

## 模型、点数及账单

**Luna** 适合日常查询及明确更改；**Terra** 适合较广泛设置及分析；**Sol** 适合复杂、含糊或长时间目标；**Sol 快速模式** 使用优先处理，成本较高并须由管理员启用。

每个 Clerk 工作区每周获得 250 个免费点数，先用免费点数，再用已购买点数。费用按有效版本费率卡，以 AI 供应商成本的两倍计算。所有者及管理员可查看用量和账目、通过 Stripe 购买点数、保存银行卡、设置有每月上限的自动充值，以及控制保留期、模型、同时目标数和每个目标预算。付款争议会暂停付费用量，未用的每周点数不会累积。

## 从文件导入菜单

附加来源菜单，并说明目标品牌或门店、货币、税务处理，以及要合并还是替换现有记录。Copilot 会先找出字段、重复项目、缺少价格、不明确的加料组及破坏性替换。确认前请检查字段映射和每个预览。附件内容只视为商家数据，Copilot 不会执行文件内的指令。

## 隐私、限制及恢复

管理员可把对话保留期设为 0、7、30 或 90 天。供应商响应会要求不在供应商端存储；为可靠性、安全、账单及争议处理，系统可另行保留检查点、审计事件、用量记录及批准证据。

Copilot 不会管理 Clerk 成员或身份验证、内部控制平台、购买银行卡或机密信息。所有操作仍受现有 HQ 权限限制。如工作进程重新启动，请从 **目标记录** 打开目标，重新登录后选择 **继续**；Copilot 会从最后检查点继续。
