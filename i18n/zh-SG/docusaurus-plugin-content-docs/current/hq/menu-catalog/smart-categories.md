---
title: 智能分类
---

:::info[适用对象]
需要为 POS 或网上点餐显示建立动态或规则式分类分组的管理员。
:::

## 开始前

- 确认正确的品牌。
- 先决定您是在管理 POS 智能分类、线上智能分类，还是两者都要。
- 先检查想要分组的商品是否已经存在。

## 打开此页面

打开 `Menu Management` -> `Smart Categories`。

## 本页用途

`Smart Categories` 可以建立比标准菜单分类树更弹性的分类分组。

在以下情况使用本页：

- 不重建基础分类结构，也能建立以显示为主的分类
- 管理智能分类里的商品关系
- 管理店铺显示设定
- 管理订单通路设定

## 主要分区

### 主清单

主清单会显示以下栏位：

- `Category Name`
- `Category Name (Alt)`
- `Display Order`
- `Button Style`
- `已发布`
- `Public Display`

常见动作包括：

- `Search`
- `Refresh`
- `Show recently removed`
- `Reorder`
- `Copy from Existing`
- `New Smart Category`

表格也会显示当前行数，并把主要工具集中在清单上方，方便您搜索、刷新、还原、重新排序、复制或新增智能分类。

### 分类编辑器

建立或编辑智能分类时，您可以处理以下栏位：

- `Category Name`
- `Category Name (Alt)`
- `Parent Category`
- `Display Order`
- `Button Style`
- `Public Display`

### 详细分页

页面可能会显示以下分页：

- `Items`
- `Shop Display Settings`
- `Order Channels`

您可以用这些分页控制智能分类的内容，以及它会出现在什么地方。

`已发布` 和 `公开显示` 是两项不同的检查。`已发布` 是分类／店铺安排的可用状态；`公开显示` 控制分类是否向顾客显示。在 `Shop Display Settings` 中编辑店铺，使用 `发布` 开关更新店铺的公开状态；保存后，该店铺会保持启用和公开。

将分类加入线上点餐，或建立新的线上店铺映射时，HQ 会默认新映射为已发布／公开。如果分类不应在每家店铺显示，请保存前逐一检查店铺。

### 还原最近移除的智能分类

如果误删了智能分类，请使用 `显示最近已移除`。

- 此开关只会显示过去 24 小时内移除的智能分类。较早移除的智能分类不会显示。
- 最近移除的行会以浅灰色背景显示。
- 最近移除的行只会显示还原动作，编辑、复制和删除动作会隐藏。
- 选择还原图标，让智能分类重新启用。
- 如果父分类未启用，或同一层已有同名的启用中智能分类，HQ 会阻止还原。

## 步骤

1. 打开 `Menu Management` -> `Smart Categories`。
2. 选择 `New Smart Category`，或打开现有分类编辑。
3. 输入 `Category Name`。
4. 需要的话，也可以输入 `Category Name (Alt)`。
5. 如果该分类应该放在其他分类下方，请选择 `Parent Category`。
6. 设定 `Display Order`。
7. 如果您要特定外观，请选择 `Button Style`。
8. 检查 `已发布`，并按需要开启或关闭 `公开显示`。
9. 保存分类。
10. 打开详细分页，管理 `Items`、`Shop Display Settings` 或 `Order Channels`。
11. 在 `Shop Display Settings` 中检查每家店铺的 `已发布` 值；需要改变顾客可见状态时，选择 `Edit` -> `发布`。
12. 如果误删了智能分类，请开启 `显示最近已移除`。
13. 找到浅灰色行，然后选择还原图标。
14. 如果 HQ 阻止还原，请先检查父分类，以及同一层是否已有同名的启用中智能分类，再重试。

## 保存后的影响

保存分类会更新智能分类纪录，但您可能仍需要检查它在店铺或通路里的显示位置。

## 如何检查你的更改

1. 回到主清单，确认该分类已经存在。
2. 检查 `Display Order`、`已发布` 和 `公开显示` 值。
3. 在相关店铺的 `Shop Display Settings` 再检查 `已发布`。
4. 查看相关详细分页，确认预期商品、店铺设定或通路已经连结。

## 如果出现问题

- 确认您编辑的是正确的智能分类类型。
- 检查问题是出在分类纪录，还是出在分页设定。
- 如果分类没有出现，请检查 `Public Display`，以及目标通路或店铺设定。
- 如果 HQ 显示分类但线上看不到，请同时检查分类 `已发布` 和店铺的 `公开显示`／`已发布` 状态。
- 如果无法还原，请检查父分类是否仍启用，以及同一层是否已有同名的启用中智能分类。

## 何时需要找老板／管理员

- 您不确定该分类应该是标准分类还是智能分类。
- 分类需要出现在多个通路，而且您无法逐一验证。
- 您正在更改现场 POS 或网上点餐使用者的导航。
