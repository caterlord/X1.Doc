:::info[Who this is for]
Managers and owners reviewing store performance and audit records.

## Before you start

- You are signed in with report access
- Printer is ready if hardcopy is needed

## What this screen is for

Use `Reports` to select a report type, choose date/context, view results, and print when needed.

## Dashboard reports

The v1.8.0 dashboards combine summary cards, charts, and detail tables so you can review a report without reading only a long printed list.

The `Sales Dashboard` can show these summary cards:

- `GROSS SALES`
- `NET SALES`
- `TOTAL DISCOUNT`
- `SERVICE CHARGE`
- `DINE-IN SALES`
- `TAKEAWAY SALES`
- `TRANSACTIONS`
- `AVG TICKET SIZE`
- `CASHIERS ACTIVE`

Its charts include `Hourly Sales Trend`, `Payment Mix`, `Sales by Category`, and `Sales by Department`. Move the pointer over a bar or donut segment to see its label and value. On a touch device, use the chart interaction supported by the device to inspect a point or segment.

The `DETAILS` tables below a dashboard provide the row-level values. Depending on the report, they can include `Period`, `Tx Count`, `Sales`, `Category`, `Department`, `Cashier`, `Discount`, `Amount`, `Hour`, or `Sales Amount`.

## Steps

1. Tap `Reports`.
2. Select the report type from the report list.
3. Choose date and any required options (for example drawer code, if prompted).
4. Wait for report to load.
5. If a dashboard is shown, review its summary cards, charts, and `DETAILS` table. Inspect a chart value by moving over the relevant bar or segment.
6. Tap `Print` if a print copy is needed.

## Review voided orders

1. Tap `Reports`.
2. Select `14. Voided Order Report`.
3. Choose the required date or reporting context.
4. Review `Cancelled At`, `Transaction`, `Table`, `Operator`, `Operator ID`, `Cancellation Reason`, `Item Details`, and `Original Item Total`.
5. Tap `Print` if you need a printed audit copy.

Use this report when you need to confirm who voided a complete order, why it was voided, and which items and original value were involved.

## What you should see

- Report selector, date controls, and `Print` button
- Report content panel updates based on selected report
- Dashboard cards, charts, and a `DETAILS` table when the selected report provides dashboard data
- `Voided Order Report` shows the operator, reason, original item total, and item details for each fully voided order

- Required report type is missing
- Printed report does not match on-screen result
